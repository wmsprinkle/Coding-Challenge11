# SunCoast Retail Data Visualization Project

This project focuses on using Python and Matplotlib to analyze and visualize business data for SunCoast Retail, a multi-location retail company. The goal is to transform raw data into clear visual insights that support business decision-making.

## Overview
The project uses Pandas and Matplotlib to explore sales trends, customer behavior, and product performance. Multiple visualization techniques are applied to answer key business questions and communicate findings effectively.

## Objectives
- Create clear and informative business visualizations
- Select appropriate chart types for different data scenarios
- Analyze trends in sales and performance over time
- Identify relationships between variables such as advertising and sales
- Present insights through a structured visual analysis

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- NumPy

## Key Features
- Time series analysis (sales trends over time)
- Multi-line and bar chart comparisons across locations and categories
- Scatter plots for relationship analysis (ad spend vs sales)
- Histograms and box plots for customer demographics
- Pie charts for market share and pricing tiers
- Multi-visual dashboard summarizing key insights

## Results
The visualizations highlight trends in sales growth, differences in performance by location and category, and relationships between advertising spend and revenue. Customer demographic patterns and purchasing behavior are also identified.

## Purpose
This project demonstrates the ability to apply data visualization techniques to real-world business problems and communicate insights clearly using Python.
